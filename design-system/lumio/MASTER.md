# Lumio design system

The binding project instructions in `AGENTS.md` and `docs/02_VISUAL_DESIGN_SYSTEM.md`, `docs/14_ART_REBUILD_DIRECTIVE.md`, and `docs/15_SCENE_LAYER_SPEC.md` take precedence. This record replaces an automatic generic recommendation that suggested claymorphism and a marketing landing page; neither applies to Lumio.

- Product: bilingual Persian/English offline-first daily-habit PWA.
- Art: approved premium tactile paper-cut diorama, 4–7 depth planes, rich cardstock fibers and coherent shadows. Day/night masters are in `art-checkpoint/`. Never use quarantined rejected SVG art.
- UI: cream stationery surfaces, deep green ink, mint/leaf actions, subtle coral/yellow accents; no plastic clay, glass or neon.
- Typography: locally hosted Estedad regular/medium/semibold/bold. True Dots display font remains unavailable and must not be simulated.
- Layout: phone width 320–430, four bottom tabs, visible check-in card, 44px touch targets, safe-area padding; tablet landscape uses side-by-side scene and panel.
- Motion: gentle cloud/hill/foreground transforms, reduced-motion off switch, accessible paper transitions.
- Source of truth for all implementation decisions: the Lumio docs, then this file.
